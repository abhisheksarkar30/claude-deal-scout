# claude-deal-scout

A Claude Code plugin that researches shopping sites (Amazon.in, Flipkart) to find the best deal
and best product for a given requirement — comparing it against your wishlist, cart, and
saved-for-later items on sites you're already logged into, plus price history: when the price was
usually lowest and when the next dip can be expected.

Read-only. It cannot buy anything, change your account, or handle your credentials.
